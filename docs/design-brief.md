# Andrea Intelligence Studio

==================================================
DESIGN SYSTEM & UX DIRECTION — HIGH PRIORITY
==================================================

IMPORTANT:
The visual quality of this application is
a top priority.

The application must NOT look like a generic
AI-generated dashboard or standard SaaS template.

Create a distinctive, premium, minimalist
and highly polished user interface.

DESIGN REFERENCE:

https://elements.envato.com/modern-performance-dashboard-EZYW6BB

Use the reference as visual inspiration.

Do not copy the design pixel by pixel.
Do not reproduce copyrighted assets.

Interpret its visual principles and create
an original design system for:

ANDREA AI OS — MARKETING INTELLIGENCE

--------------------------------------------------
1. OVERALL DESIGN DIRECTION
--------------------------------------------------

Design philosophy:

- Minimalism
- Swiss-inspired typography
- Premium SaaS aesthetics
- Strong visual hierarchy
- Editorial precision
- Functional simplicity
- Modern data visualization

The interface should feel like a
professionally designed digital product
created by an experienced UI/UX designer.

Not a generic AI dashboard.

Not a Bootstrap admin template.

Not an overly decorative startup website.

--------------------------------------------------
2. COLOR PALETTE
--------------------------------------------------

Use a refined neutral palette.

Primary background:
#F5F5F3

Card background:
#FFFFFF

Sidebar background:
#E8E8E6

Primary text:
#171717

Secondary text:
#777777

Borders:
#E4E4E4

Accent color:
#8FE000

Use lime green strategically for:

- Selected navigation items
- Active filters
- Primary actions
- Important KPI highlights
- Selected chart data

Do not overuse the accent color.

The overall interface should remain
predominantly neutral.

--------------------------------------------------
3. TYPOGRAPHY
--------------------------------------------------

Use a modern premium sans-serif font.

Preferred fonts:

- Inter
- Geist
- Manrope

Use consistent typography.

Large bold numbers for KPIs.

Clear section headings.

Compact secondary labels.

Avoid oversized unnecessary headings.

Use careful letter spacing,
line height and font weights.

--------------------------------------------------
4. LAYOUT
--------------------------------------------------

Desktop-first responsive dashboard.

Create a fixed or collapsible left sidebar.

Sidebar width approximately 230–250px.

Main dashboard should use a
responsive 12-column grid.

Use consistent spacing.

Recommended spacing system:

8 / 12 / 16 / 24 / 32 px

Use generous whitespace.

Cards should have:

- Rounded corners
- Subtle borders
- No heavy shadows
- Comfortable padding

Avoid excessive nesting of cards.

--------------------------------------------------
5. SIDEBAR DESIGN
--------------------------------------------------

Create a sophisticated sidebar.

Top:

ANDREA AI OS
Marketing Intelligence

Below:

Client selector

Navigation:

- Přehled
- Organika & automatizace
- Výkon webu
- Výkon kampaní
- Reporty

Bottom:

- Nastavení
- Uživatelský profil

Use minimalist line icons.

Active navigation item:

Lime background with dark text.

Inactive navigation:

Neutral background.

Use subtle hover interactions.

--------------------------------------------------
6. DASHBOARD KPI CARDS
--------------------------------------------------

Create elegant KPI cards.

Each card should include:

- Metric label
- Large metric value
- Percentage change
- Small trend indicator
- Optional mini sparkline

Example:

ROAS

4.86x

+12.4% vs. previous period

Highlight only one or two
important cards using lime green.

Other cards remain white.

Avoid excessive badges
and colorful status indicators.

--------------------------------------------------
7. CHART DESIGN
--------------------------------------------------

Charts must be clean and precise.

Use Recharts or an equivalent library.

Prefer:

- Smooth line charts
- Minimalist area charts
- Horizontal bar charts
- Compact comparison charts
- Simple conversion funnels
- Sparklines

Avoid:

- 3D charts
- Heavy gradients
- Excessive colors
- Decorative illustrations
- Unnecessary animations

Use a consistent chart palette:

- Lime green
- Dark charcoal
- Neutral gray
- Muted green

Provide:

- Clear axis labels
- Tooltips
- Date filtering
- Hover interactions
- Legends where needed

Charts must be readable.

--------------------------------------------------
8. TABLE DESIGN
--------------------------------------------------

Data tables are extremely important.

Create professional analytics tables.

Features:

- Clean headers
- Subtle row separators
- Sticky headers where appropriate
- Search
- Sorting
- Filtering
- Pagination
- Column visibility
- Export

Use compact but comfortable spacing.

Avoid excessive cell borders.

Use subtle hover states.

Keep numerical values aligned.

--------------------------------------------------
9. MICROINTERACTIONS
--------------------------------------------------

Add subtle professional interactions.

Examples:

- Smooth sidebar transitions
- Button hover states
- Tab transitions
- Dropdown animations
- Chart tooltip animations
- Loading skeletons

Keep animations short.

Recommended duration:

150–250 ms

Respect reduced-motion preferences.

Do not add unnecessary animation.

--------------------------------------------------
10. USER EXPERIENCE
--------------------------------------------------

Prioritize usability over decoration.

The marketing manager must quickly find:

- Marketing performance
- ROAS
- PNO
- Campaign results
- Creative performance
- Website conversions
- Organic traffic
- SEO results
- Automation performance

Important information should be
accessible within one or two clicks.

Support consistent global filtering.

When switching clients,
all dashboard sections should update.

Show:

- Last synchronization time
- Data source
- Missing data warnings
- Error states
- Empty states
- Loading states

Avoid unnecessary modal windows.

--------------------------------------------------
11. CREATIVE PERFORMANCE UX
--------------------------------------------------

Design a premium creative analytics section.

Use a combination of:

- Creative thumbnails
- Compact KPI data
- Comparison tables
- Performance charts

Allow users to visually compare
Meta Ads creatives.

Display:

- Creative image or video thumbnail
- Campaign
- Spend
- CTR
- CPC
- CPL
- ROAS

Use meaningful sorting and filters.

The experience should feel like
a professional ad intelligence tool.

--------------------------------------------------
12. RESPONSIVENESS
--------------------------------------------------

Desktop:

Full analytics dashboard.

Tablet:

Adaptive grid.

Mobile:

Simplified KPI overview.

Use horizontally scrollable
data tables when necessary.

Ensure comfortable touch targets.

--------------------------------------------------
13. DESIGN QUALITY CONTROL
--------------------------------------------------

Before considering the design complete:

Review every screen for:

- Consistent spacing
- Typography hierarchy
- Color consistency
- Alignment
- Readability
- Visual balance
- Responsive behavior
- Accessibility
- Navigation clarity

Remove generic AI UI patterns.

Avoid:

- Random gradients
- Excessive shadows
- Large colorful hero sections
- Generic illustration cards
- Excessive glassmorphism
- Unnecessary badges
- Repetitive card layouts
- Random icon styles

Deliver an original,
premium-quality SaaS interface.

--------------------------------------------------
14. IMPORTANT FINAL INSTRUCTION
--------------------------------------------------

Design the application as if it were
a premium European B2B SaaS product.

The result should look suitable for
a real commercial product.

Prioritize:

1. Excellent UX
2. Clean visual hierarchy
3. Beautiful typography
4. Functional analytics
5. Consistent design system
6. Fast and intuitive navigation

Do not sacrifice functionality
for visual decoration.

Before implementation, establish
reusable design tokens and components.

Then apply them consistently
across the entire application.
